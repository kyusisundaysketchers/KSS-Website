# Kyusi Sunday Sketchers — Website Prototype

This is the Phase 1 visual/interaction prototype, now centered on the upcoming KSS 1st Anniversary event.

## Current state

- Uses the real KSS logo supplied for the project.
- Does not require the actual sketches, posters, or event photos yet.
- Incorporates the upcoming Fiestang Pinoy 1st Anniversary event as the primary homepage story.
- Uses styled placeholders so we can finalize layout, hierarchy, typography, and mobile behavior first.
- Responsive mobile layout with horizontally scrollable sketch cards.
- Lightweight interactions: sticky navigation, hover treatment, mobile menu, anchor navigation.
- No build step and no JavaScript framework.

## Replace later
